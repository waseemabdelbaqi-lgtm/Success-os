# Global Digital Library

Taxonomic lesson routes (prefixed to protect SUCCESS OS root routes):

```
/digital-library/[region]/[country]/[curriculumType]/[educationLevel]/[subject]/[chapter]/[lesson]
```

Requested hierarchy maps to this path under the `digital-library` namespace because a bare `app/[region]/…` would capture `/admissions`, `/student`, etc.

## Prototype lesson

IB Physics · Quantum Physics · Photoelectric Effect  
`/digital-library/international-systems/global/ib/dp/physics/quantum-physics/photoelectric-effect`

Includes Modules A–F: DeepKnowledgeBase, ThreeDCanvas (R3F), SmartWorkspace, FloatingScientificCalc, SolvedExamples, GamifiedQuiz.
