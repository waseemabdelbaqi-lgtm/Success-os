# ADR-0050.1 — Jordan is the reference curriculum import implementation

**Decision ID:** ADR-0050.1  
**Status:** Accepted  
**Date:** 2026-07-30  
**PR:** #50.1 Jordan Curriculum Example (Reference Implementation)  
**Depends on:** [ADR-0049](./ADR-0049-interactive-lesson-engine-single-runtime.md), [ADR-0050](./ADR-0050-curriculum-import-compiler.md)

---

## Decision

Jordan Grade 1 Mathematics (Part 1 → Unit 1 → Lesson 1) is the **reference implementation** for all future curriculum imports.

The hierarchy and import flow are **completely generic**. Adding Saudi Arabia, Egypt, USA, AP, IGCSE, IB, A Level, EST, ACT, etc. requires a **new connector + registry content only** — **not** changes to the ILE runtime.

## Reason

- Prove Country → Curriculum → Grade → Subject → Book → Unit → Lesson → ILE Package end-to-end  
- Keep ILE as the only renderer  
- Avoid curriculum-specific lesson UIs  

## Alternatives Considered

| Alternative | Verdict |
|-------------|---------|
| Jordan-specific lesson renderer | ❌ Rejected (ADR-0049) |
| Hard-code Jordan fields into ILE | ❌ Rejected |
| AI rewrite during reference import | ❌ Rejected |

## Consequences

- Generic schema: `success-os.curriculum-hierarchy.v1`  
- Reference path documented and tested  
- Every imported lesson → exactly one ILE package  
- `Published = true` only after all verification gates
