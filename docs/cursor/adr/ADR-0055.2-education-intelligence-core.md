# ADR-0055.2 — Education Intelligence Core (EIC)

**Status:** Accepted  
**Date:** 2026-07-30  
**PR:** #55 AI Teacher Engine (Educational Intelligence foundation)  
**Depends on:** ADR-0055 (ATE), ADR-0055.1 (ADHT), ADR-0049 (ILE)  
**Forward:** Deeper ML predictors activate under roadmap **#59 Learning Intelligence** without changing EIC contracts.

## Context

Success OS is not building unconstrained AI chat. It is building **Educational Intelligence**: an engine that thinks like an experienced teacher — continuously understanding what the student knows, why they are confused, which prerequisite is missing, how fast they learn, whether they are guessing, and which explanation works best.

## Decision

1. Introduce **Education Intelligence Core (EIC)** as the Learning DNA + adaptive intelligence layer on top of ATE.
2. After **every** ATE interaction, EIC updates durable **Learning DNA** (18 dimensions + confusion log + explanation fingerprints).
3. EIC produces:
   - Teacher understanding snapshot
   - Adaptive strategy (struggling / steady / advanced)
   - Predictions (next lesson, review, likely confusion, exam risk, unmastered skills)
   - Grounded insight utterances (e.g. repeated confusion from weeks ago)
4. **Explanation novelty:** each strategy carries a fingerprint; fingerprints are never reused.
5. Engine kind for this wave is `heuristic_teacher_intelligence` — production-grade rules grounded in ATE memory / skills / confusion history. It does **not** invent curriculum facts or fake neural-network certainty.
6. Learning Intelligence (#59) may replace scoring models behind the same schemas.

## Consequences

- Lifelong educational profiles accumulate with every conversation.
- Digital Human Teacher + ATE consume EIC strategy/insights without owning DNA persistence.
- Reviewers can audit DNA files under `library/education-intelligence-core/`.

## Alternatives rejected

- Treating EIC as a free-form LLM that invents student history.
- Resetting DNA per session (forgets the learner).
- Repeating identical explanations when the student is still confused.
