# ADR-0050.2 — Jordan Reference Dataset is the official curriculum metadata standard

**Decision ID:** ADR-0050.2  
**Status:** Accepted  
**Date:** 2026-07-30  
**PR:** #50.2 Jordan Reference Dataset & Verification  
**Depends on:** [ADR-0049](./ADR-0049-interactive-lesson-engine-single-runtime.md), [ADR-0050](./ADR-0050-curriculum-import-compiler.md), [ADR-0050.1](./ADR-0050.1-jordan-curriculum-reference.md)

---

## Decision

Jordan Grade 1 (multi-subject national curriculum tree) is the **official reference dataset** for Success OS curriculum import.

Every future country/board must produce the same hierarchy shape, the same **metadata-only** lesson projection, and the same six-dimension verification report before any ILE package may publish.

ILE remains the **only** educational runtime. There is no curriculum-specific renderer and no second lesson runtime.

## Reason

- Elevate #50.1 from a single Math lesson proof into a **country-level standard**  
- Encode pending / restricted / rejected states so publishing rules are enforceable  
- Keep import as a compiler that emits ILE packages only  

## Alternatives Considered

| Alternative | Verdict |
|-------------|---------|
| Treat Jordan as a one-off import | ❌ Rejected — no reusable standard |
| Country-specific lesson UI | ❌ Rejected (ADR-0049) |
| AI-generate lesson bodies during dataset seed | ❌ Rejected (out of scope) |
| Publish rejected lessons for preview | ❌ Rejected — rejected never publish |

## Consequences

- Dataset schema companion: `success-os.jordan-reference-dataset.v1`  
- Hierarchy remains `success-os.curriculum-hierarchy.v1`  
- Official hierarchical IDs: `JO` → `JO-NATIONAL` → `JO-NATIONAL-G01` → `…-MATH` → `…-B01` → `…-U01` → `…-L01`  
- Global Subject Registry: `SUB-00001` Mathematics · `SUB-00002` Physics · `SUB-00003` Chemistry · `SUB-00004` Biology · …  
- Cross-country alias rule: Jordan `رياضيات` / USA `Mathematics` / Egypt `رياضيات` → same `SUB-00001`
- Global lesson metadata contract: UUID, globalLessonId, globalSubjectId, graph links, Bloom/difficulty/skills, `aiReady=false`, published/verified/archived  
- Lesson verification: source / rights / structure / metadata / package / publishing  
- Dashboard exposes grades, subjects, verified/pending/rejected packages, progress, validation errors, rights warnings  
- Future SA/EG/USA/AP/IGCSE/IB connectors copy this metadata + verification + ID contract
