# الحالة الحالية — SUCCESS OS

تاريخ الاستلام: 17 يوليو 2026

## الملخص التنفيذي

المستودع تطبيق Next.js 15 وReact 19 وTypeScript strict، ويحتوي على:

- واجهة تسويقية رئيسية وثماني بوابات عامة.
- مصادقة Firebase وجلسات HttpOnly ونظام صلاحيات لـ15 دورًا.
- لوحات أدوار عامة، مع بوابة طالب مستقلة تحت `/student`.
- تجربة كتب ودروس تجريبية مع تقدم ومرجعيات وملاحظات وتظليل محفوظة في `localStorage`.

المشروع ليس جاهزًا للإنتاج بعد. المحتوى التعليمي تجريبي، ولا توجد طبقة إنتاج للشراء أو التفعيل أو الإشعارات أو الفيديو أو الذكاء الاصطناعي أو النشر الأكاديمي الموثق.

## حالة بيئة العمل المحلية

- نظام التشغيل: Windows 10.
- `node`: مثبت الآن (`v24.18.0`).
- `npm`: مثبت الآن (`11.16.0`).
- `git`: غير مثبت أو غير متاح في `PATH`.
- الاعتماديات مثبتة، و`npm run lint` و`npm run typecheck` نجحا بعد إصلاحات TypeScript/ESLint.
- خادم التطوير يعمل محليًا على `http://localhost:3000` مع `FEATURE_AUTH_ENABLED=false`.
- يوجد الآن `package-lock.json` بعد `npm install`. `vercel.json` ما زال يطلب `npm ci` وهو متوافق بعد وجود القفل.

## حالة الشيفرة

- عدد الملفات المفحوصة: 153 ملفًا ظاهرًا في المستودع.
- ملفات الاختبار: صفر (`*.test.*` و`*.spec.*`).
- لا توجد أوامر unit أو integration أو E2E أو accessibility أو link checks في `package.json`.
- CI الحالي يشغّل ESLint وPrettier وTypeScript وbuild و`npm audit`.
- فلتر المكتبة في `book-filters.tsx` أُصلح (سلسلة الدولة ← النظام ← المنهاج ← الصف).

## البيانات والمحتوى

- الكتب والمناهج والوحدات والدروس مصدرها الوحيد `content/demo/catalog.ts`.
- البيانات معلمة صراحة بأنها Demo، لكنها تظهر أيضًا كقيم وإحصاءات افتراضية في لوحة الطالب.
- تقدم الطالب والمفضلة والملاحظات والتظليل والسجل والملف تحفظ محليًا في المتصفح، وليست مرتبطة بالمستخدم أو Firestore.
- لا يوجد منهاج وطني أردني حاليًا.
- لا توجد بوابة تحقق من حقوق الاستخدام أو التغطية الأكاديمية أو سجل مصادر.
- لا توجد عملية نشر أو مراجعة أو اعتماد محتوى.

## حالة الميزات المطلوبة

- المصادقة: بنية Firebase موجودة، وتتطلب مفاتيح صحيحة واختبارًا فعليًا.
- الطالب: بوابة مستقلة موجودة.
- الباحث عن عمل: لوحة دور عامة فقط، ولا توجد رحلة مستقلة أو state machine.
- الشركاء: صفحات تسويقية فقط، ولا توجد رحلة انضمام أو state machine.
- الشراء والتفعيل: غير موجودين.
- الإشعارات: واجهة تجريبية ثابتة فقط.
- AI Gateway: غير موجود.
- الفيديو والنص والترجمة والاستئناف الزمني: غير موجودة.
- إكمال الدرس واستئناف القراءة: موجودان محليًا عبر `localStorage`.
- RTL/LTR: مدعومان داخل بوابة الطالب، لكن `app/layout.tsx` يبدأ دائمًا بـ`lang="en"`، ولغة الكتاب لا تتحكم باتجاه القارئ بصورة مستقلة.
- الجوال: تخطيطات responsive موجودة؛ شريط الطالب السفلي يعرض سبعة عناصر فقط.

## سلامة المصادقة

الجلسات تستخدم Firebase Admin وHttpOnly cookies وHMAC metadata. توجد مخاطرة حرجة يجب معالجتها في دفعة أمنية مستقلة: `POST /api/auth/register` يثق في `uid` وبيانات الهوية المرسلة من العميل دون التحقق من ID token يثبت ملكية ذلك المستخدم.

## أول عطل أُصلح في هذه الدفعة

فلتر مكتبة الطالب كان لا يربط `systemId` بأي عنصر واجهة، ولذلك لم يكن يعمل التسلسل:

الدولة ← النظام التعليمي ← المنهاج ← الصف.

تم إصلاحه في `components/student-portal/books/book-filters.tsx` بإضافة اختيار النظام التعليمي، وربط cascade الحقول التابعة، والإبقاء على نوع النظام كفلتر اختياري منفصل.
